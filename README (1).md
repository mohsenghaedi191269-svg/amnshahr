# امن‌شهر | آموزش مدیریت بحران و پدافند غیرعامل

وب‌سایت آموزشی و مستقل برای آمادگی در برابر بحران، پدافند غیرعامل و مشارکت شهروندی در آگاهی عمومی.

## ساختار
- `index.html`: کل سایت به‌صورت یک فایل ایستا (HTML، CSS و JavaScript) با Tailwind از CDN
- `.nojekyll`: اجازه‌ی انتشار بدون پردازش Jekyll در GitHub Pages

## اجرای محلی
فایل `index.html` را در مرورگر باز کنید. برای بارگذاری فونت و Tailwind به اینترنت نیاز است.

## انتشار در GitHub Pages
1. در تنظیمات ریپو، بخش **Pages** را باز کنید.
2. در بخش Source گزینه‌ی **Deploy from a branch** را انتخاب کنید.
3. شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب و ذخیره کنید.

آدرس سایت: https://koolerabiiiiii-dot.github.io/amnshahr/

## محدودیت‌ها
- محتوای این سایت جایگزین دستورالعمل رسمی سازمان مدیریت بحران کشور نیست.
- بخش «چشم شهروند» غیرفعال است؛ راه‌اندازی آن نیازمند مجوز حراست شهرداری است و نباید بدون آن منتشر شود.
- این ریپو هیچ داده‌ی شخصی یا گزارش شهروندی را ذخیره نمی‌کند.

## منابع
منابع هر درس در بخش «منابع» همان صفحه‌ی درس ذکر شده‌اند.

## نسخه‌ی اپلیکیشن (PWA)
این سایت را می‌توان روی گوشی نصب کرد و پس از اولین بارگذاری بدون اینترنت هم خواند.

فایل‌های مربوط به این بخش:
- `manifest.webmanifest`: مشخصات اپلیکیشن (نام، رنگ، آیکون)
- `sw.js`: سرویس‌ورکر برای کار آفلاین
- `icons/`: آیکون‌های PNG
- `logo.svg`: لوگوی اصلی

**نصب روی گوشی:** در مرورگر Chrome (اندروید) گزینه‌ی «نصب برنامه» یا «افزودن به صفحه‌ی اصلی» را بزنید. در Safari (iPhone) از دکمه‌ی اشتراک‌گذاری گزینه‌ی «افزودن به صفحه‌ی اصلی» را انتخاب کنید.

**نکته:** سرویس‌ورکر فقط روی آدرس امن (https) کار می‌کند؛ GitHub Pages این شرط را دارد.
